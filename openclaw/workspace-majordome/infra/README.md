# Fiches d'infra

Une fiche par service, tenue par Jarvis (ex : `immich.md`).

Modèle :

    # Immich
    - Machine : immich (192.168.1.13)
    - Stack : /chemin/vers/immich-stack (docker compose)
    - Version installée : vX.Y.Z (au AAAA-MM-JJ)
    - Notes de version : dépôt GitHub immich-app/immich
    - Mise à jour : étapes qui ont marché, dans l'ordre
    - Pièges : ce qui a coincé et comment c'était réglé
    - Historique : AAAA-MM-JJ — ce qui a été fait
